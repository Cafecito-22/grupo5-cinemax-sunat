# Imágenes originales de SUNAT

Imágenes proporcionadas por el usuario para este rediseño:

- `sunat-digital.png`: fotografía de servicios digitales con computadora.
- `sunat-atencion.png`: ilustración de atención al contribuyente.
- `sunat-isotipo.png`: isotipo SUNAT proporcionado como imagen independiente.

Se conservan sin modificar como fuentes del proyecto. La web las sirve desde Object Storage privado bajo `sunat/v2/`, a través de las referencias autorizadas de la API; no desde el paquete público de Vercel. La base guarda únicamente el nombre y la ruta del recurso.
